# Ravenovy progresivní matice – IQ test

Statický web hostovaný na GitHub Pages.

🔗 **https://navidofek-cmyk.github.io/iq_raven**

## Co to je

Neverbalní IQ test inspirovaný Ravenovými progresivními maticemi. Doplňuješ chybějící díl do 3×3 matice geometrických tvarů.

## Technologie

- HTML + CSS + JavaScript
- Tvary kreslené přes Canvas API (žádné obrázky)
- Žádný backend, žádné závislosti

## Spuštění lokálně

```bash
python3 -m http.server 8765
```

Otevři http://localhost:8765
